# ClawChat v1.4.26

## Android workflow simplification

- Start server-backed workspaces in Inbox. The former Now screen is now
  Attention, a secondary destination for requests and active-work summaries.
- Add recognizable sidebar and action icons, remove duplicate Settings shortcuts,
  and use consistent Search all labels.
- Keep project conversations and task-agent threads in a panel over the plan.
  Opening a discussion focuses the bottom composer; opening a run for review does
  not automatically open the keyboard.
- Move task notes and step editing into task detail. Add step opens a bottom
  input panel; child tasks reuse existing completion, deletion and undo actions.
  Back returns to the parent task.
- Preserve failed note/step drafts, isolate them per task, and prevent duplicate
  submissions. Step retries reuse their operation key.

## Verification and limitations

- Android: 559 unit tests passed; lint has no errors (7 existing warnings), and
  the debug APK builds successfully. Release artifacts are verified separately
  by the unified release workflow.
- Real-device keyboard, large-font, nested navigation and upgrade smoke tests
  remain to be performed. Offline queued changes still require synchronization.
- macOS uses temporary ad-hoc signing, not Apple Developer ID notarization.
  Installation or updates may request Gatekeeper/Keychain approval again.
  Updater signature verification remains enabled.
