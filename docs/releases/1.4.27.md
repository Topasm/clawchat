# ClawChat v1.4.27

## 주요 변경

- 데스크톱 작업 경로 연결을 간소화했습니다. 현재 머신의 폴더 선택 후 ‘여기서 실행하기’로 경로와 실행 머신을 연결합니다. 연결 전에 폴더를 읽을 수 있는지 확인하며, 연결 실패 시 재시도할 수 있습니다.
- 데스크톱 Inbox에서 AI 배치 승인 후 프로젝트로 이어갈 수 있는 안내를 추가했습니다. 단일 작업은 프로젝트 Outline에서 선택되며, 기존 Undo 동작을 유지합니다.
- 데스크톱·Android 프로젝트 작업의 주 버튼이 실행 상태에 맞춰 바뀝니다. Ready 작업 실행, 기존 실행 열기, 질문 답변, 결과 검토를 구분하며 실행 상태를 확인하지 못하면 새 실행을 제안하지 않습니다.
- 작업 상세 화면의 기본 정보량을 줄였습니다. Android는 제목·완료·마감일·대화를 한 카드에 모으고 설명·태그·추가 상태 선택을 접었습니다. 데스크톱은 미설정 반복 옵션과 스킬 선택을 접었습니다.
- Android 하단 메모 입력·하위 작업·연결 작업과 오류 표시는 유지했습니다. 세부 정보의 펼침·접힘 상태를 스크린리더에 전달합니다.

## 설치 및 주의 사항

- macOS 빌드는 유료 Developer ID 인증서 없이 **임시 서명(ad-hoc)** 합니다. Apple 공증 빌드가 아니므로 설치·업데이트 시 Gatekeeper 경고나 Keychain 권한 요청이 다시 나타날 수 있습니다.
- Android에서 다른 기기의 에이전트 실행 상태가 바뀌면 프로젝트를 새로고침해 최신 상태를 확인하세요. 이번 변경은 백그라운드 폴링을 추가하지 않습니다.
- 데스크톱 작업 경로는 폴더 선택기를 쓰거나 절대 경로를 입력하세요. 폴더 읽기 확인은 쓰기 권한이나 실행 CLI의 정상 동작까지 보장하지 않습니다.
- 실기기에서 큰 글씨, 키보드, 스크린리더를 포함한 사용성 확인은 별도로 필요합니다.
