# ClawChat v1.4.23

## Improvements

- Android Inbox now previews suggested project/task placement and supported deadlines before approval. Keep an item standalone, choose its location, defer it, or undo the latest placement.
- Saved Inbox review choices and cached previews survive app restarts. Related follow-up suggestions can use recent approved placements as context.
- Deadline interpretation uses the capture time and device timezone. Date-only deadlines retain their intended calendar day; ambiguous dates are not guessed.
- Android task widgets refresh after completion, show completion failures, and query open tasks before pagination so completed items cannot crowd out active work.
- Android chat polling slows down for ordinary conversations while active runs refresh more frequently.
- Updated web/server dependencies and build tooling, reduced renderer startup payload, and fixed Korean catalog loading for both raw and HTTP-decoded gzip responses.

## Updating

- Update the server alongside Android. Inbox review persistence requires database migration `b2d4f6a8c013`; back up the server database before upgrading and use the normal migration/startup procedure.
- Desktop installers: Linux x64, Windows x64, macOS Apple Silicon. Android includes a signed APK and AAB; use the APK for direct installation over an existing release build.
- Previewing Inbox suggestions does not start agents or automatically apply graph changes. Approval remains explicit.

## Verification scope

Automated web, server, and Android tests cover the changed workflows. Signed platform builds, package inventory, and checksums are verified by release CI. Physical-device widget behavior and real-device in-place updates still need manual verification.
