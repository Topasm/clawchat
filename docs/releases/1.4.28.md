# ClawChat v1.4.28

## 주요 변경

- 프로젝트와 작업 상세에서 실행 머신과 작업 폴더를 바로 확인하고 변경할 수 있습니다. 저장 후 프로젝트 카드·상세·작업공간의 위치 정보가 함께 갱신됩니다.
- macOS 데스크톱에서 폴더 선택기를 연 뒤 다른 폴더로 이동할 때 앱이 멈추던 문제를 수정했습니다. 네이티브 폴더 창이 열려 있는 동안 앱 UI를 막지 않습니다.
- 작업 반복 기능을 제거했습니다. 데스크톱·Android의 반복 설정과 표시를 숨기고, 작업 완료 시 다음 항목을 자동 생성하지 않습니다. 기존 작업은 삭제하지 않으며 캘린더 일정 반복은 그대로 유지합니다.
- 작업 경로 저장 실패를 화면에 표시하고 재시도할 수 있도록 했으며, 저장에 성공한 경우에만 편집 중인 경로를 정리합니다.

## 설치 및 주의 사항

- 작업 반복 중단은 서버 동작도 포함하므로 데스크톱·Android 클라이언트와 서버를 함께 업데이트하세요.
- 기존 작업에 저장된 반복 메타데이터는 호환성과 데이터 보존을 위해 남아 있지만 더 이상 다음 작업을 생성하지 않습니다.
- macOS 빌드는 유료 Developer ID 인증서 없이 **임시 서명(ad-hoc)** 합니다. 설치·업데이트 시 Gatekeeper 경고나 Keychain 권한 요청이 다시 나타날 수 있습니다.
- macOS 폴더 선택 수정은 자동 검사와 릴리즈 빌드로 검증합니다. 실제 Mac에서 Desktop 등 다른 폴더로 이동하고 선택·취소·재열기를 확인하는 실기기 검증은 별도로 필요합니다.
