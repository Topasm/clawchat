# ClawChat v1.4.24

## Android workflow and UI improvements

- Replaced persistent bottom navigation with a modal left drawer. Open it from the menu button; Inbox and Projects are directly accessible. Search and Settings return to the originating screen. Local workspaces expose only supported features.
- Inbox and chat share a compact bottom composer, consistent spacing and typography, and accessible action buttons. Voice input is available in the chat More menu.
- Inbox approval cards show essential information. Edit placement in one sheet, choose an existing project and parent task, and include or exclude the suggested deadline. Changes are saved before explicit approval; stale graph revisions block saving.
- Fixed Inbox task-opening actions. Approved project work opens its selected outline node. Project conversations offer a Plan return action, and project selection restores after activity/process recreation.
- Deep task outlines use compact indentation and show the selected task's ancestor path. Long selection labels wrap, and placement actions can wrap for enlarged fonts.
- Conversation drafts persist locally by workspace and thread. Restore/save failures expose Retry and do not silently overwrite existing drafts. Drafts are excluded from cloud backup and device transfer; only completed disk writes survive abrupt process termination.

## Verification and update notes

- Android automated tests, lint and Debug APK build passed locally. Release CI verifies signed Android APK/AAB, desktop packages, updater manifests and checksums.
- No physical Android device or emulator was available. Small-screen layout, large fonts, keyboard, drawer gestures, back navigation, and in-place updates still require manual device verification.
- Android drawer opening is button-driven to avoid conflicts with Android edge-back and schedule swipe gestures; an open drawer supports swipe-to-close.
- This release adds no server database migration beyond v1.4.23. Keep the server updated for Inbox review APIs.
- Desktop installers are provided for Linux x64, Windows x64 and macOS Apple Silicon. Use the signed Android APK for direct installation over a release build.
